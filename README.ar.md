# YTDISK — نسخة المتصفح

[English](README.md) · **العربية**

ملف يدخل داخل فيديو بنمط اختبار بدقة 4K، ثم يخرج الفيديو ويعود الملف، والبايتات مطابقة تمامًا. بلا خادم، وبلا رفع، وبلا حساب.

هذه إعادة بناء للمتصفح لأداة بايثون الأصلية [`ahmedfox1/YtDisk`](https://github.com/ahmedfox1/YtDisk). المُرمِّز، وشيفرة Reed–Solomon، وطبقة scrypt/AES-GCM، وحاوية MP4، والواجهة — كلها تعمل محليًا داخل التاب.

## التشغيل

افتح `index.html` مباشرة في Chromium (Chrome أو Edge أو Brave). الصفحة مصممة لتعمل من `file://`.

إذا كان متصفحك يمنع الوصول إلى الملفات المحلية، قدّم المجلد عبر خادم محلي:

```sh
cd ytdisk
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080/`.

**المتطلبات:** WebCodecs مع ترميز وفك ترميز H.264. تُستخدم دقة 4K عند توفرها، وإلا تنتقل الواجهة إلى 1080p. Chrome وEdge على سطح المكتب هما الخيار الأكثر أمانًا.

## الاستخدام

1. **حزم** — اختر ملفًا، وحدّد حجم الخلية وتصحيح الأخطاء والإخراج، وأضف كلمة مرور اختيارية، ثم أنشئ ملف MP4 ونزّله.
2. ارفع الفيديو إلى YouTube Studio بوصفه **غير مُدرج**، وانتظر حتى يكتمل تجهيز **2160p**.
3. نزّل ملف MP4 بدقة 2160p (مثلًا عبر `yt-dlp`).
4. **فك** — اختر ذلك الملف في الصفحة، وأدخل كلمة المرور إن استُخدمت، ثم نزّل الملف الأصلي.

زر الفحص الذاتي يفك الفيديو داخل الصفحة ويقارن بصمة SHA-256 قبل أن ترفعه.

## الصيغة

تتبع صيغة الفيديو أداة بايثون:

- شبكة منطقية 1920 × 1080، بإخراج 3840 × 2160 أو 1920 × 1080، و30 إطارًا في الثانية.
- خلايا 4 أو 8 بكسل؛ 30 إطار ترويسة تتبعها إطارات البيانات.
- Reed–Solomon فوق GF(256)، `prim = 0x11d`، `fcr = 0`، `N = 255`، مع 32 أو 64 أو 0 بايت تعويض، وكلمات ترميز متشابكة.
- AES-256-GCM اختياري مع scrypt (`N = 2^15, r = 8, p = 1`).
- بصمة SHA-256 للبايتات الأصلية تُخزَّن في الترويسة وتُتحقق عند الفك.

## الاختبارات

```sh
node tests/rs.test.js
node tests/cdp.mjs --url "file://$PWD/index.html" --wait-ms 3500 --eval-file tests/ui-e2e.js
```

يقارن `rs.test.js` شيفرة JavaScript ببايتات متجهات بايثون `reedsolo` ويتحقق من تصحيح الأخطاء. ويقود `ui-e2e.js` عناصر الصفحة الحقيقية: اختيار ملف، وإنشاء، وفحص ذاتي، وفك، ومقارنة البايتات، بكلمة مرور وبلا كلمة مرور. يحتاج مشغّل Chromium بلا واجهة إلى وجود `chromium-browser` في `PATH`.

## الحدود، بصراحة

هذا عرض تعليمي، وليس خدمة تخزين. إعادة ترميز، أو تغيير منطقة، أو حذف للفيديو قد يتلف الحمولة. ورفع البيانات في هيئة فيديو قد يخالف شروط المنصات. أبقِ الرفع غير مُدرج، واستخدم قناة تجريبية، واحتفظ دائمًا بنسخة حقيقية من أي شيء يهمك. الجيجابايت يعادل نحو 42 دقيقة من فيديو 4K، والرفع والتنزيل يستغرقان وقتًا أطول من ذلك.
